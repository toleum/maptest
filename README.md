# Открытая карта района

Справочник заведений Ауэзовского района Алматы, который собирается автоматически из открытых источников и публикуется как карта на GitHub Pages.

**Источники:**
- [OpenStreetMap](https://www.openstreetmap.org) через Overpass API, лицензия ODbL;
- [Overture Maps](https://overturemaps.org), слой Places, лицензия CDLA Permissive 2.0.

Закрытые карты (2ГИС, Яндекс, Google) не используются.

## Что делает сборка

1. Берёт границу района из OSM и все заведения, учреждения и остановки внутри неё.
2. Берёт из Overture места внутри той же границы. Закрытые точки и точки с низкой уверенностью (< 0.5) отбрасываются.
3. Склеивает дубли: одинаковое название в пределах 60 м считается одним объектом. Недостающие телефон, сайт и адрес берутся из Overture.
4. Раскладывает объекты по категориям и помечает источник: «в обоих», «только OSM» или «только Overture».
5. Публикует карту, `places.csv` и историю изменений `data/changes.md`.

Точки «только Overture» — это кандидаты на проверку и ручное добавление в OSM. В карточке каждой такой точки есть ссылка на редактор. Импортировать их в OSM автоматически нельзя.

## Запуск

1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. **Actions → «Обновить карту» → Run workflow.** Первая сборка занимает 5–15 минут.
3. Карта появится по адресу `https://<пользователь>.github.io/<репозиторий>/`.

Дальше карта обновляется сама каждый понедельник, а также после любого изменения `config.json` или скриптов.

## Другой район

Поменяйте в `config.json` поля `title` и `district_regex`, например `"Бостандыкский|Бостандық"`. Районы Алматы: Алатауский, Алмалинский, Ауэзовский, Бостандыкский, Жетысуский, Медеуский, Наурызбайский, Турксибский.

## Файлы

| Файл | Назначение |
|---|---|
| `config.json` | район, порог склейки дублей |
| `scripts/fetch_osm.py` | выгрузка из OSM, с запасными зеркалами Overpass |
| `scripts/fetch_overture.py` | выгрузка из Overture (последний релиз) |
| `scripts/build.py` | сведение, категории, CSV, история изменений |
| `site/index.html` | карта 2D |
| `site/3d.html` | карта 3D: дома по этажности (OpenFreeMap) + заведения |
| `data/places.csv` | справочник (обновляется ботом) |
| `data/changes.md` | что появилось и пропало от сборки к сборке |
